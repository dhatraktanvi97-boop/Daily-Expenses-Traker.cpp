# Daily Expense Tracker 💰

Hi! This is my C++ project, **Daily Expense Tracker**.

I built this project to practise my C++ concepts and understand how programming can be used to solve everyday problems.

The main idea is simple: keep track of daily expenses, calculate total spending and manage expense records.

## What can it do?

- Add a new expense.
- View all recorded expenses.
- Calculate total spending.
- Delete an expense when needed.
- Check and reject invalid amount inputs.
- Save expense records using file handling.
- Load previously saved expenses when the program starts.

## Concepts I used

While building this project, I practised:

- Classes and Objects
- Constructors
- Encapsulation
- Arrays of Objects
- Loops (`for`, `do-while`)
- Switch Statements
- Functions
- Basic Input Validation
- File Handling (`fstream`)

## Technologies

- Programming Language: C++
- Compiler: C++11 compatible compiler
- Platform: Console Application

## How to Run

Compile the program:

```bash
g++ main.cpp -o expense_tracker
```

Run it:

```bash
./expense_tracker
```

For Windows:

```bash
expense_tracker.exe
```
